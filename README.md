# joshua-developer-github-scratch

A tiny "hello world" command-line app, implemented using only the Python
standard library.

## Usage

```sh
python hello.py
# Hello, world!

python hello.py Jake
# Hello, Jake!

python hello.py Jake --upper
# HELLO, JAKE!

python hello.py --help
```

## Tests

Run the tests from the repository root with:

```sh
python -m unittest
```
